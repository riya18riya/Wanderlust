# Wanderlust – Travel Website

Wanderlust is a responsive travel website designed to help users explore beautiful travel destinations.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Responsive website layout
- Mobile navigation menu
- Featured destination cards
- About Us section
- Responsive header and footer

## Project Structure
```text
Wanderlust/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
└── README.md
```

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
